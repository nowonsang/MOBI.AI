# BodyFit AI 기능정의

> 내 몸을 기억하는 자동차. 운전자의 체형과 직접 조정한 이력을 학습해 탑승할 때마다 맞춤 시트 자세를 추천하고, 정차 중 목표 자세까지 단계별로 안내한다.

- 공모전: 현대자동차그룹 차량용 앱 개발 공모전 (Pleos Playground)
- 우선순위: **P0** = 11/15 기획서·MVP 시연 필수 · **P1** = 2차 PT(12/3~4) 전 · **P2** = 향후 확장
- 할 일과 진행 상황은 [todo.md](./todo.md)에서 관리한다.

## 핵심 방향: 가이드 조절

Pleos SDK 현황(2026-11-09 확인) 기준으로 **시트 조회는 가능하지만 시트 제어는 아직 불가**하다.

| SDK | 상태 | 영향 |
| --- | --- | --- |
| Vehicle State (조회, `CAR_SEATS` 등) | 사용 가능 | 시트 위치 실시간 조회, 정차 판단 |
| NaviHelper | 사용 가능 | 주행 상황 판별 |
| Vehicle Control (제어, `CONTROL_CAR_*`) | 준비 중 (신청 불가) | 시트 자동 조절 불가 |
| TextToSpeech / SpeechToText | 준비 중 | 음성 피드백 불가 |
| FusedLocation | 준비 중 | 위치 기반 상황 판별 불가 |

그래서 MVP는 **앱이 시트를 움직이지 않는다.** 대신 시트 위치를 실시간으로 읽으면서 사용자가 직접 목표 자세까지 맞추도록 안내한다.

- 학습은 그대로 유지: 사용자가 실제로 맞춘 최종 위치를 조회해 개인 보정에 반영한다.
- 자동 조절과 음성은 해당 SDK가 열리면 적용하는 확장 로드맵(P2)으로 둔다.

## 심사 기준 대응 (1차, 배점 비공개)

| 항목 | 이 기획에서 보여줄 것 |
| --- | --- |
| 차량특화성 | 실제 시트 위치를 실시간으로 읽는 정차 중 가이드, 주행 후 피드백 |
| 창의성 | 수동 조정 이력으로 개인 착좌 습관을 학습 (C 그룹) |
| 기술 활용성 | Vehicle SDK(Seat, Brake, DrivingMode 조회), NaviHelper를 핵심 흐름에 사용. 제어·음성 SDK 확장 계획 |
| 사업성 | 타깃(다운전자 가정, 공유차, 장거리 운전자), 예상 MAU, 리텐션 |
| 개발 산출물 (가산점) | 시연 영상, GitHub 저장소(소스 + APK) |

## 안전 원칙 (모든 기능에 적용)

| ID | 원칙 |
| --- | --- |
| S-1 | 가이드 조절은 정차 상태(P단 또는 주차 브레이크)에서만 시작. 주행 중에는 추천만 저장하고 안내하지 않는다. |
| S-2 | 가이드 중 주행이 시작되면 즉시 안내를 중단하고 화면을 닫는다. |
| S-3 | 운전 중 시선을 끄는 화면 표시 금지. 주행 중 알림은 최소화한다. |
| S-4 | 신체·사진 데이터는 동의 후 수집. 원본 사진은 저장하지 않고 추정 수치만 남긴다. |
| S-5 (P2) | 자동 조절 도입 시: 사용자 승인 후에만 이동, 즉시 정지 수단 제공, 1회 이동량 상한(예: 등받이 ±5°, 앞뒤 ±30mm). |

## 기능

### A. 프로필

| ID | 우선 | 기능 | 설명 |
| --- | --- | --- | --- |
| A-1 | P0 | 운전자 프로필 등록 | 이름, 키, 몸무게, 성별(선택), 운전 성향(선택) |
| A-2 | P0 | 프로필 선택 | 탑승 시 차량 화면에서 선택, 최대 5명 |
| A-3 | P1 | 카메라 체형 추정 | 포즈 인식으로 다리·상체·팔 비율 추정 |
| A-4 | P2 | 자동 인식 | 승인된 탑승자 식별(키 연동, 휴대폰 등) |

### B. 추천·가이드 조절

| ID | 우선 | 기능 | 설명 |
| --- | --- | --- | --- |
| B-1 | P0 | 시트 상태 실시간 조회 | Vehicle SDK Seat로 앞뒤, 높이, 등받이 각도 읽기. 지원 축은 `checkXXXCapabilities`로 확인 |
| B-2 | P0 | 목표 자세 추천 | 체형 데이터 + 인체공학 규칙(무릎·팔꿈치·시야각) + 개인 보정(C-2)으로 축별 목표값 계산 |
| B-3 | P0 | 차이 표시 | 현재와 목표의 축별 차이 표시 (예: "등받이 3° 더 뒤로, 높이 1단계 위로") |
| B-4 | P0 | 가이드 조절 | 사용자가 시트 버튼을 조작하는 동안 실시간 조회로 진행 표시. 축별 "조금 더 / 지나쳤어요 / 딱 좋아요 ✓", 모든 축이 허용 오차 안이면 완료 |
| B-5 | P0 | 여기서 완료 | 목표와 다르게 맞춰도 그 위치를 최종값으로 인정 (C-1 학습 데이터) |
| B-6 | P1 | 이전 자세 불러오기 | 지난번 최종 위치를 목표로 다시 가이드 |
| B-7 | P2 | 자동 조절 | Vehicle Control SDK가 열리면 승인 후 시트 직접 이동 (S-5 적용) |

### C. 학습 (핵심 차별점)

| ID | 우선 | 기능 | 설명 |
| --- | --- | --- | --- |
| C-1 | P0 | 최종 위치 기록 | 가이드 종료 시점과 하차 직전의 실제 시트 위치를 조회해 추천값과의 차이(델타) 저장 |
| C-2 | P0 | 개인 보정 | 축별 델타 가중 평균(최근일수록 가중)을 다음 추천에 반영 (예: 이 사람은 늘 등받이 +3°) |
| C-3 | P1 | 상황별 자세 | 출퇴근, 장거리, 시내 등 상황별 자세 프로필 (Odometer, NaviHelper 활용) |
| C-4 | P1 | 추천 근거 설명 | "지난 5번 중 4번 등받이를 뒤로 조정하셔서 반영했어요" |

### D. 피드백

| ID | 우선 | 기능 | 설명 |
| --- | --- | --- | --- |
| D-1 | P1 | 주행 후 편안함 체크 | 장거리(예: 60분 이상) 주행 후 정차하면 터치 선택지로 질문 ("편했어요 / 허리 / 목·어깨 / 다리가 불편했어요") |
| D-2 | P1 | 부위별 보정 규칙 | 불편 부위를 축 보정으로 변환 (예: 허리 불편 → 등받이 각도·요추 지지 재추천) |
| D-3 | P1 | 다음 탑승 시 제안 | 쌓인 피드백으로 보정한 자세 제안 |
| D-4 | P2 | 음성 피드백 | STT/TTS가 열리면 음성 입력·음성 질문으로 확장 |

### E. 웹 컴패니언 (이 저장소)

| ID | 우선 | 기능 | 설명 |
| --- | --- | --- | --- |
| E-1 | P1 | 등록 화면 | A-1 + A-3 |
| E-2 | P1 | 자세 이력 | 조정·피드백 타임라인, 자세 변화 그래프 |
| E-3 | P0 | 데모 모드 | 실제 차량 없이 시트 시뮬레이터로 가이드 조절 흐름 시각화 (영상·PT 백업용) |

## MVP 시연 시나리오

1. 탑승 후 프로필 선택 (A-2)
2. 정차 확인 (S-1) → 현재 시트 위치 조회 (B-1)
3. 기본 추천 + 개인 보정으로 목표 자세 계산 (B-2, C-2) → 축별 차이 표시 (B-3)
4. 사용자가 시트 버튼을 조작하면 화면이 실시간으로 "조금 더 뒤로… 딱 좋아요 ✓" 안내 (B-4)
5. 사용자가 등받이를 목표보다 3° 더 뒤로 맞추고 완료 → 최종 위치와 델타 저장 (B-5, C-1)
6. 다음 탑승 때 +3° 반영된 목표와 근거 문구 표시 (C-2, C-4)

| --- | --- | --- | --- |
| B-1, B-4, C-1 | Vehicle Seat 조회 (`CAR_SEATS`) | 사용 가능 | 지원 축·조회 주기·에뮬레이터 지원 확인 필요 |
| S-1, S-2 | Vehicle Brake·DrivingMode 조회 (`CAR_DRIVE`) | 사용 가능 | P단·속도 신호를 어떤 API로 읽는지 확인 |
| C-3 | Odometer, NaviHelper | 사용 가능 | - |
| B-7 | Vehicle Control (`CONTROL_CAR_*`) | 준비 중 | 열리는 시점 미정 |
| D-4 | SpeechToText, TextToSpeech | 준비 중 | 열리는 시점 미정 |
| 체중 | - | - | 카메라로 측정 불가 → 직접 입력. 압력 센서는 P2 |

## 범위 밖 (MVP)

- 앱이 시트를 직접 움직이는 자동 조절 (B-7, P2)
- 음성 입력·안내 (D-4, P2)
- 주행 중 자세 안내
- 실시간 압력 분포 분석
- 얼굴·생체 정보 기반 자동 인식
